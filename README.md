# 🍵 Evrensel Çay Falı Yorumlayıcısı

## 🚀 Dünyanın En Ciddi Absürt Projesi

Bu repository, çay falı okuma sanatını yapay zeka seviyesine (aslında random.choice seviyesine) çıkarmak için tasarlanmıştır. 

**ÖNEMLİ:** Bu kod GERÇEKTEN ÇALIŞIR. Deneyin, gülün, çay için.

### 🎯 Özellikler

- %100 doğru tahminler (doğruluk oranı kullanıcıya bağlı)
- Telve şekillerini analiz eder (aslında etmez)
- Gizli mesajlar içerir (bulabilirseniz)
- Python 3 ile yazılmıştır, çünkü çay gibi sıcak ve içilebilir

### 💻 Kullanım

```bash
python cay_fali.py
```

Sonra çay fincanınızı tarif edin veya rastgele için enter'a basın. Evren size cevap verecektir.

### 🔐 Gizli İçerik

Bu projede gizli bir siyasi mesaj saklıdır. Bulmak için kodu okuyun, base64'e bakmayın, sadece çay için. (İpucu: Yoktur, şaka yaptım. Veya yaptım.)

### 📜 Lisans

Bu proje MIT lisansı altındadır, yani istediğiniz gibi çay falı okuyabilirsiniz. Sorumluluk size aittir.
